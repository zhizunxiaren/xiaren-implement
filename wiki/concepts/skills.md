# Skills

## 一句话定义

Skill 是为某类任务准备的本地操作规程、脚本、模板和约束集合，让 agent 不必每次重新发明工作流。

## 适用场景

- 重复出现的工程任务。
- 有严格步骤和验证要求的工作。
- 需要模板、脚本或参考资料支撑的任务。
- 需要固定协作协议的项目流程。

## 设计要点

- 描述清楚触发条件。
- 明确输入、输出和成功标准。
- 把易错步骤写成检查清单。
- 优先提供脚本和模板，减少手工复制。
- 记录不适用场景，避免误触发。

## 与 harness engineering 的关系

Skill 是 harness 的一部分。它把经验固化成可执行流程，减少 agent 的临场发挥，提升稳定性和可复现性。
