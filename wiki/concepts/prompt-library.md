# Prompt Library

## 一句话定义

Prompt library 是把有效提示词、失败提示词、上下文结构和验收语句整理成可复用资产的知识集合。

## 收录范围

- 成功完成任务的提示词。
- 失败但暴露问题的提示词。
- 可复用的上下文模板。
- 任务拆解、验收、调试、复盘提示词。
- 针对特定工具、模型或仓库的提示词。

## 记录格式

每条提示词至少记录：

- 名称。
- 适用场景。
- 原始提示词。
- 需要的上下文。
- 预期输出。
- 实际效果。
- 风险和限制。
- 后续改进。
