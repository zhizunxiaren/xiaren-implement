# xiaren-implement

一个用于沉淀 vibe coding、harness engineering、skills、MCP、提示词工程和 AI 工程落地经验的本地 LLM Wiki。

## 如何使用

1. 把原始资料放入 `raw/`，把未整理想法放入 `inbox/`。
2. 让 Codex 按 `AGENTS.md` 的 ingest 流程整理资料。
3. 在 `wiki/` 阅读、检索、更新综合后的知识。
4. 每次新增或修改 wiki 内容时，同步更新 `wiki/index.md` 和 `wiki/log.md`。

## 核心边界

- `raw/` 是原始资料层，尽量保持不可改写。
- `wiki/` 是 LLM 维护的综合知识层。
- `AGENTS.md` 是维护协议和项目 schema。
- 不提交任何密钥、token、credential 或隐私材料。
